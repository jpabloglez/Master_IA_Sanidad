# Máster en Aplicaciones de la Inteligencia Artificial en Sanidad / Master's Programme in Artificial Intelligence Applications in Healthcare 🌐🤖

📘 **Ejemplos de código y ejercicios de programación** para el [Máster en Aplicaciones de la Inteligencia Artificial en Sanidad](https://cemp.es/master-aplicaciones-inteligencia-artificial-sanidad/) de CEMP.
📘 **Code examples and programming exercises** for the [Master's Programme in Artificial Intelligence Applications in Healthcare](https://cemp.es/master-aplicaciones-inteligencia-artificial-sanidad/) at CEMP.

Los cuadernos están pensados para ejecutarse en **Google Colab**, sin instalación previa.
The notebooks are designed to run on **Google Colab**, with no local setup required.

---

## Contenido / Contents

Este repositorio recoge el material del **Módulo 2**, disponible en dos idiomas:
This repository holds the material for **Module 2**, available in two languages:

| Carpeta / Folder | Descripción / Description |
|---|---|
| [`Modulo_2/spanish`](Modulo_2/spanish) | Cuadernos en español, diapositivas por edición, datasets y documentación / Notebooks in Spanish, slides per intake, datasets and docs |
| [`Modulo_2/english`](Modulo_2/english) | Cuadernos en inglés y datasets / Notebooks in English and datasets |

### Bloques temáticos / Topic blocks

🔵 Los cuadernos siguen la numeración de las clases del módulo:
🟠 The notebooks follow the numbering of the module's classes:

- **2.1 — Introducción a Python / Introduction to Python.** Fundamentos del lenguaje, continuación, monitorización con TensorBoard y un caso práctico de gestión de citas médicas.
- **2.2 — Programación / Programming.** Entornos virtuales, importación de módulos, herencia y polimorfismo, nomenclaturas y ocultación, regresión lineal.
- **2.3 — Aprendizaje automático y profundo / Machine and deep learning.** Perceptrón y redes neuronales desde cero, preprocesado y estructuración de datos, exploración visual, extracción de características, matriz de correlación, aumento de datos (incluido TorchIO), desbalance de clases con SMOTE, regresión logística, árboles de decisión, evaluación de modelos, tensores, mapas de activación y un proyecto COVID con TensorFlow/Keras.
- **2.9 — Ciencia de datos / Data science.** Librerías NumPy y Pandas.

### Diapositivas y grabaciones / Slides and recordings

📖 [`Modulo_2/spanish/Clases`](Modulo_2/spanish/Clases) contiene un cuaderno por **edición del máster** con los enlaces a las diapositivas y grabaciones de las clases semanales.
📖 It contains one notebook per **programme intake**, with links to the slides and recordings of the weekly classes.

Ediciones disponibles / Available intakes (12): `0722` · `1122` · `0323` · `0523` · `0723` · `1123` · `0324` · `0524` · `0724` · `1124` · `0225` · `0425`

### Datos / Data

🗂️ [`Modulo_2/spanish/datos`](Modulo_2/spanish/datos) reúne los conjuntos de datos empleados en los ejercicios (Framingham Heart Study, enfermedad cardiaca, ictus, diabetes, ILPD, seguros médicos), con una [descripción de cada uno](Modulo_2/spanish/datos/README.md).
🗂️ It gathers the datasets used in the exercises, each one documented in its own README.
